# Elzu's First Birthday Website

A responsive, single-page birthday invitation and first-year memory gallery designed for free GitHub Pages hosting.

## Included
- `index.html` — the complete website (HTML, CSS and JavaScript in one file)
- `assets/` — place your photos here

## Personalize the photos
You do not need to edit the code if you use the filenames below:

- `assets/elzu-hero.jpg` — main photo on the invitation
- `assets/memory-01.jpg` — newborn / first hello
- `assets/memory-02.jpg` — first smile
- `assets/memory-03.jpg` — playtime / exploring
- `assets/memory-04.jpg` — giggles / funny moment
- `assets/memory-05.jpg` — family photo
- `assets/memory-06.jpg` — recent photo

Use JPG or JPEG images and keep the filenames exactly as written. If you want different filenames, edit the matching `src="assets/..."` values in `index.html`. If a photo is not present yet, a decorative placeholder appears automatically.

You can also change the memory card headings and captions by editing the text in `index.html`.

## Publish on GitHub Pages
1. Sign in to GitHub or create an account at https://github.com/.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io` (replace the placeholder with your GitHub username).
3. Upload `index.html` and the `assets` folder to the repository's root. Make sure `index.html` is at the root, not inside another folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes, then visit `https://YOUR-GITHUB-USERNAME.github.io/`.

Every time you update the photos or code and commit the changes, GitHub Pages will publish the updates.
